# FXS Intelligence — FX Funding Checker

داشبورد استعلام محل‌های مجاز تأمین ارز بر اساس «اولویت ارزی» کد تعرفه کالاهای زیرمجموعه وزارت صنعت، معدن و تجارت. این اپ **نسخه مستقل** برای استقرار Streamlit است و بعداً می‌تواند به داشبورد Helios HS Checker متصل شود.

## راه‌اندازی در Streamlit Community Cloud

1. همه فایل‌های **داخل پوشه** `FXS_FX_Funding_Checker` را در ریشه یک مخزن GitHub قرار دهید (حفظ `data/` و `.streamlit/`).
2. به [share.streamlit.io](https://share.streamlit.io) بروید و **Create app / New app** را انتخاب کنید.
3. مخزن و شاخه را انتخاب کنید و Main file path را `app.py` بگذارید.
4. Deploy کنید. نیاز به API Key، دیتابیس یا Google Cloud نیست.
5. اگر خواستید در همان مخزن پروژه قبلی قرار دهید، فایل‌ها را داخل پوشه `fx_funding/` بگذارید و مسیر Main file path را `fx_funding/app.py` تعیین کنید.

اجرای محلی:

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## امکانات

- نمای کلی: ۸٬۱۵۱ ردیف، توزیع اولویت و پوشش پنج مسیر تأمین ارز
- استعلام کد ۸ رقمی با پشتیبانی از ارقام فارسی و عربی
- جست‌وجوی معکوس بر اساس شرح، تعرفه، دفتر تخصصی، اولویت و منبع تأمین ارز
- استعلام گروهی با ورودی Excel/CSV یا paste چند کد
- خروجی **Excel واقعی (`.xlsx`)** با سربرگ، فیلتر، حالت RTL و CSV با UTF-8 BOM
- مقایسه فایل جدید: افزوده، حذف‌شده، تغییر اولویت، شرح و دفتر
- فعال‌سازی آزمایشی داده جدید در همان نشست (بدون تغییر فایل اصلی)

## داده و منطق

- `data/source_announcement.xlsx`: نسخه اصلی فایل پیوست کاربر، بدون تغییر
- `data/tariffs.csv`: نسخه پاک‌سازی‌شده قابل استفاده در برنامه؛ `hs_code` همیشه ۸ رقم است
- `data/metadata.json`: اطلاعات منشأ، SHA-256 و شفافیت تاریخ انتشار/اجرا
- `engine.py`: قواعد خالص و مستقل از Streamlit برای اتصال آینده به HS Checker
- `excel_io.py`: خواندن و نوشتن Excel بدون نیاز به pandas یا openpyxl

## به‌روزرسانی پایدار داده

از تب «نسخه‌ها و تغییرات» فایل جدید را بارگذاری و اختلاف‌ها را مشاهده کنید. برای انتشار پایدار نسخه جدید، فایل `data/tariffs.csv` را پس از ارزیابی صحت و منبع خبر جایگزین، تاریخ و هش را در `metadata.json` اصلاح و مجدداً Deploy کنید. آپلود داخل اپ برای آزمایش، داده منتشرشده را دائمی تغییر نمی‌دهد.

## نکات و محدودیت‌های عملیاتی

- **دامنه:** تنها ثبت سفارش‌هایی که سازمان مجوزدهنده ارزی آن‌ها وزارت صمت است؛ برای سازمان‌های دیگر قابل تعمیم نیست.
- فهرست شامل مجازبودن *روش‌های مندرج در اطلاعیه* است؛ تضمین‌کننده تخصیص، دسترسی به ارز، عدم وجود مجوزهای دیگر، امکان مچینگ یا نهایی‌شدن معامله نیست.
- تاریخ انتشار و زمان شروع لازم‌الاجراشدن **در فایل اکسل مشخص نیست**؛ در UI تاریخ نسخه از زمان استعلام جدا شده و تا تأیید رسمی «تأیید نشده» باقی می‌ماند.
- فایل یک ردیف با شرح خالی (`44071120`) دارد؛ استعلام آن حذف نشده است.
- اپ از Google Fonts برای دریافت آنلاین **Vazirmatn** استفاده می‌کند؛ در حالت بدون اینترنت fallback روی Tahoma است. هیچ فایل فونتی در بسته قرار ندارد.
- این بسته ماژول **مستقل** است؛ به‌علت موجود نبودن ZIP پروژه قبلی در فایل‌های این گفتگو، تغییری در کد HS Checker قبلی صورت نگرفته و مسیر `General` و `Steel & Metals` دست‌نخورده است.
